Управление админами

По умолчанию единственным админом является владелец группы.

  1. /set_admin
    • Минимальный уровень доступа: главный админ (200)
    • Требует указать целевого пользователя

    Назначает/снимает админа. Использование:

    /set_admin {ранг}

    Доступные ранги (в скобках указан уровень доступа):

    • никто (0)

    • модератор (100)

    • главный админ (200)

    Главный админ имеет все права, а модератор все кроме бана и назначения других админов. Ранг никто - снять админа.

Управление группой

  1. /pin
    • Минимальный уровень доступа: модератор (100)
    • Требует указать целевое сообщение

    Закрепить указанное сообщение

  2. /unpin
    • Минимальный уровень доступа: модератор (100)
    • Требует указать целевое сообщение

    Открепить указанное сообщение

  3. /set_rules
    • Минимальный уровень доступа: главный админ (200)

    Установить правила группы. Использование: 

    /set_rules {правила}

    Для форматирования текста используются html теги. Список тегов можно посмотреть здесь

  4. /set_hello
    • Минимальный уровень доступа: модератор (100)

    Установить приветствие группы. Использование: 

    /set_hello {правила}

    Для форматирования текста используются html теги. Список тегов можно посмотреть здесь

  5. /toggle_hello
    • Минимальный уровень доступа: модератор (100)

    Включить/выключить приветствие группы

Муты

  1. /mute
    • Минимальный уровень доступа: модератор (100)
    • Требует указать целевого пользователя

    Выдать мут пользователю. Использование:

    /mute {число}{единица времени} причина

    Поддерживаемые единицы времени:

    • s - секунды

    • m - минуты

    • d - дни

    • w - недели

    Внимание: мут более чем на год будет засчитан как мут навсегда из-за ограничений Telegram

  2. /unmute
    • Минимальный уровень доступа: модератор (100)
    • Требует указать целевого пользователя

    Размутить пользователя

Inline режим

Запрос состоит из названия режима и его аргументов. Пример:

@EbO_total_security_bot mode something

  • mode - режим

  • something - аргументы режима

Доступные режимы:

  • whisper

    Отправить секретное сообщение по юзернейму или user_id. Принимает аргументы в формате @EbO_total_security_bot whisper @юзернейм текст сообщения.

  • anti-whisper

    Тоже самое что и whisper, но наоборот: сообщение не сможет посмотреть тот пользователь, которого вы указали.

  • text2windings

    Перевести английский текст в windings

  • windings2text

    Перевести текст на windings в обычный
