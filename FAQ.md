# Часто задаваемые вопросы

## Хочу такой же бот себе, что мне нужно?

- Сервер/компьютер готовый работать 24/7, желательно на Linux
- MySQL база данных
- Redis база данных
- API ключи для работы /ai, /ai_ds и /cat
- Белый IP адрес (для polling необязательно) или свой Telegram Bot API сервер
- Очень желательны знания Python и aiogram

## Есть ли какая нибудь информация по структуре кода?

Есть! Код состоит из main.py, который загружает указанные модули в нём из папки modules, регистрирует обработчики команд, устанавливает вебхук (если включён api_mode webhook), инициализирует модули и запускает http сервер (если включён api_mode webhook). Модули состоят из роутера и обработчиков команд.
